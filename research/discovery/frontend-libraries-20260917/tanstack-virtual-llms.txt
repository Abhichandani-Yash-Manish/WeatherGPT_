# TanStack Virtual docs

> Virtualize only the visible content for massive scrollable DOM nodes at 60FPS in TS/JS, React, Vue, Solid, Svelte, Lit, Angular & Marko while retaining 100% control over markup and styles.

- [Docs index](https://tanstack.com/virtual/latest/docs/index.md): This same Markdown index.
- [LLMs index](https://tanstack.com/virtual/latest/llms.txt): This same Markdown index.
- [Library home](https://tanstack.com/virtual/latest)
- [GitHub](https://github.com/tanstack/virtual)
- Packages: @tanstack/virtual-core, react-virtual.
- Frameworks: React, Solid, Vue, Svelte, Lit, Angular, Marko.

Use this index as the routing layer for the docs. Fetch one linked Markdown page at a time, and prefer framework-specific pages when the user names a framework.
